▸1 Captureidle no photo yet

The photo is downscaled to a 1600 px long side in the browser; that downscaled image is exactly what is POSTed to /detect and /estimate, so every pixel coordinate on this page shares one coordinate system with the server.

▸2 Board detectionidle waiting for a photo

POST /detect returns a geometric quad (TL, TR, BR, BL). Geometry cannot know which physical corner is a8, so the labels start as a guess and the server auto-rotates the reading by chess plausibility — until you touch a handle, at which point your labelling wins and auto-rotation is switched off. When the server does rotate, this page adopts that rotation into its own corner labels, so the handles, the table below and the rectified preview keep describing the same board as the position on the right. The photo above carries the quad; drag a handle there to correct it.

▸3 Rectify & geometryidle waiting for corners

A client-side homography, for checking the labelling only — the server re-derives its own geometry from the corners and reads whole pieces off the original photo. Projected aspect below 0.62 means the camera is close to board level and pieces occlude each other; mean luma below 55 is dim enough to degrade recognition.

▸4 Square samplingidle waiting for a read

64 tall full-piece boxes are cut from the original photo (they overlap on purpose — a piece is taller than its square) and resized to the model's input. These are the exact tensors the classifier saw.

▸5 Classificationidle waiting for a read

A 13-class distribution per square, stateless and rule-free — an illegal-looking board is still reported as ok. Click any cell to open it in the inspector.

▸6 Orientationidle waiting for a read

Which corner is a8 is not knowable from geometry. With untouched auto-detected corners the read is posted with autorotate=1 and the server picks the rotation whose reading is most plausible; once you edit a corner or rotate the labels, that is authoritative and no rotation is applied. A rotation the server applies is adopted here as well — the corner labels shift by the same amount, so the whole page ends up describing one single orientation.
