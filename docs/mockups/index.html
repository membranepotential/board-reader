board-reader · UI mockups

Static mockups of the whole reader UI — the phone at /camera, the desktop live viewer at /, and the one-shot pipeline inspector at /snapshot. Every page is drawn from the real Svelte source under packages/viewer/ui/src/, with each state captioned. Nothing here runs: no camera, no socket, no node.

how to read the annotations

shipped — this is what the app does today decided — agreed design, not built yet proposal — my suggestion, undecided

Guiding principle carried through every page: minimize button presses. Where the system can resolve something itself, it resolves it, states what it decided in one quiet line, and offers a one-tap escape hatch — rather than asking the operator to press a control repeatedly until the world looks right.
