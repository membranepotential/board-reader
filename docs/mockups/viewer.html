/ — the desktop live viewer

One card per board, in a stable order, fed by a single WebSocket of position events. The card is a stateless readout: no move list, no history, no legality — an illegal-looking board is still reported as ok. Everything below is drawn from lib/components/live/* and lib/stores/positions.svelte.ts.

1connectingshipped

Before the first event there is nothing to draw — the socket state is the whole UI.

2a live board, settledshipped

The full card. The drawn board is settled.placement when the event carries one, else prior.placement, else the raw read — never the raw string blindly, because a raw argmax can spell an impossible board. Rings annotate; they never fill.

3a move in flight — pending squaresshipped

The node's ingest-stabilizer debounces the board: a raw read must hold before the settled board adopts it. Squares the settled board has not adopted yet are drawn as dashed amber rings, and the piece drawn under the ring is still whatever was last settled there.

5per-square confidenceproposal

Today the live card shows one position-level confidence bar plus yellow rings on squares under 0.5; the actual per-square numbers exist on the wire (square_dist) but only /snapshot renders them. Proposal: a numbers toggle on the card that prints each square's top-class probability in its corner, reusing the snapshot page's confidence map colouring.

6raw · prior · settledproposal

Every position event carries up to three readings of the same frame. The card collapses them into one drawn board plus rings, which is right for a glance and wrong for a diagnosis. Proposal: a three-way switch on the card that names which one you are looking at, defaulting to settled exactly as today.

layerwhat it ishow the card shows it today
placement — raw The stateless per-square argmax. May spell an impossible board (two white kings, a pawn on the back rank). Never suppressed, never rewritten. Printed as the placement: FEN string only — never drawn.
prior The nearest possible board decoded out of the same distribution. Lists every square it relabelled, cheapest first. Drawn if no settled exists; its relabelled squares get red rings.
settled The temporally debounced board — a change must hold before it is adopted, so a display does not flicker on every hand crossing the board. Drawn when present; its un-adopted squares get dashed amber rings.
Correction to the brief: the live viewer does not stream three positions. One PositionEvent per frame carries the raw placement plus optional prior and settled boards, and the card draws exactly one of them — settled ?? prior ?? raw — annotating the rest with rings. The dashed amber ring is real and shipped; the layer switch and per-square numbers above are proposals.
Also shipped, not drawn above: the card's ↻ button rotates that board's on-screen picture only (display, saved per board — it does not touch what the node reads), and a second board simply appears as another card in the same flex row.
